# SignSpeak OCR source transfer

This archive contains the OCR source package, handoff docs, and evaluation
scripts. It deliberately excludes generated evaluation benchmark images/results,
original-source snapshots, Tesseract binaries/language models, and Python
virtual environments.

Extract into your existing CanAI_Team_E Git checkout, keeping the ocr/
subfolder. Do not overwrite teammates' files outside ocr/.

See ocr/docs/WINDOWS_VALIDATION.md for setup instructions. This source
snapshot has NOT been validated on the target Windows machine.

Before uploading to a public repository, review docs for environment-specific
paths and confirm your team's project-sharing permissions.

Includes one synthetic bilingual notice at ocr/examples/bilingual_notice.png
for an offline OCR smoke test.
